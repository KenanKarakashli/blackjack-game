# Blackjack Game

An interactive, browser-based Blackjack game built to practice complex JavaScript logic and state management. 

## Features
* **Dynamic Card Drawing:** Generates random card values using JavaScript Math functions.
* **Game State Logic:** Automatically calculates sums and determines winning (Blackjack), losing (out of the game), or continuing states.
* **Interactive UI:** Real-time updates to the DOM based on player actions.

## Technologies Used
* HTML5
* CSS3
* Vanilla JavaScript

## Live Demo
[View Live Project](https://KenanKarakashli.github.io/blackjack-game/)

## Key Learnings
* Managing state using JavaScript Objects and Arrays.
* Utilizing `for` loops to iterate through data and render it to the screen.
* Implementing complex `if/else` conditional logic to enforce game rules.
* Generating random numbers and standardizing outputs using `Math.random()` and `Math.floor()`.
